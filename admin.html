Falta conectar Firebase

El panel ya está listo, pero todavía no tiene a dónde guardar los productos. Para conectarlo:

  1. Entrar a console.firebase.google.com y crear un proyecto.
  2. Agregar una aplicación web y copiar los datos que muestra la consola.
  3. Pegarlos en el archivo js/firebase-config.js.
  4. En la consola, activar Authentication (usuario y contraseña) y Firestore. Storage no hace falta: las fotos van adentro de Firestore.
  5. Crear el usuario con el que va a entrar quien carga los productos.
